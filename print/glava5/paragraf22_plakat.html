Мир детства — что такое эссе-повествование

Эссе-повествование

Рассказ о событиях по порядку: завязка → развитие действия → кульминация → развязка

Эссе-рассуждение

Тезис → аргументы → вывод (см. §24)

Эссе-описание

Описание предмета, явления, впечатления

Завязка→ Развитие действия→ Кульминация→ Развязка

«Чудетство» (М. Яснов) = чудо + детство — пример того, как из двух слов рождается новое, волшебное.
