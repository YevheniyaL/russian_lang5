§2. Число имён существительных — проверка (стр. 20–25)

Проверь себя сам

Впиши ответ на месте черты. Когда закончишь все 5 — переверни лист вверх ногами и прочитай ответы внизу страницы, чтобы проверить себя.

  1. Море — моря, друг —
  2. Существительное «молодёжь» имеет форму только числа.
  3. «Ножницы, очки, ворота» — существительные только числа.
  4. У существительных только множественного числа не определяется.
  5. «Иртыш, Алатау» — имена , поэтому имеют форму только единственного числа.

Ответы (переверни лист):

1) друзья    2) единственного    3) множественного    4) род    5) собственные

Вопросы, которые может задать мама (устно)

Не показывай ребёнку эту часть — просто зачитай вопросы вслух и сверься с ответом в скобках.

  1. Какие две формы числа есть у имени существительного? (единственное и множественное)
  2. Назови группу существительных, у которых бывает только единственное число. (любая из: вещественные — молоко; отвлечённые — радость; собирательные — листва; собственные — Иртыш)
  3. Назови группу существительных, у которых бывает только множественное число. (любая из: парные предметы — очки; вещественные — дрова; отвлечённые — каникулы; собственные — Карпаты)
  4. Можно ли определить род у слова «ножницы»? Почему? (нет, потому что оно стоит только во множественном числе)
  5. Что такое безэквивалентная лексика? Приведи пример. (слова одной культуры, которых нет в готовом виде в других языках; например, юрта или матрёшка)
