Число имён существительных

Единственное и множественное — а у некоторых слов только одна форма

книгаед. число — один предмет
→
книгимн. число — много предметов

Только единственное число

форму множественного не образуют

вещественныемолоко, бензин
отвлечённыерадость, счастье
собирательныелиства, молодёжь
имена собственныеИртыш, Алатау

Только множественное число

формы единственного не существует

парные предметыочки, ножницы, ворота
вещественныеконсервы, дрова, дрожжи
отвлечённыеканикулы, сутки, потёмки
имена собственныеКарпаты, Петушки
Важно: у существительных только множественного числа род не определяется — у слова «ножницы» нет ни мужского, ни женского, ни среднего рода.

Язык и культура — безэквивалентная лексика

слова одной культуры, которых нет в готовом виде в других языках

русская культураматрёшка, сарафан, скатерть-самобранка
казахская культураюрта, шанырак, бешбармак, Алдар-Косе
